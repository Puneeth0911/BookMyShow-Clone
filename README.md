# BookMyShow Clone – Movie Ticket Booking System

A movie ticket booking application developed using Java and Spring Boot, inspired by BookMyShow. The application is designed to manage customers, theatres, movies, shows, ticket bookings, and payment-related operations.

## Features
- Customer management
- Theatre management
- Movie and show management
- Ticket booking management
- RESTful API development
- Database integration using PostgreSQL
- Entity relationships using Spring Data JPA and Hibernate

## Tech Stack
- **Language:** Java
- **Backend:** Spring Boot, Spring MVC
- **ORM:** Hibernate, Spring Data JPA
- **API:** REST APIs
- **Database:** PostgreSQL
- **Tools:** Eclipse, Postman, Git, GitHub

## Project Objective
To develop a scalable backend application that demonstrates Java backend development concepts, Spring Boot architecture, REST API implementation, and database management.

**Project Status:** In Progress
